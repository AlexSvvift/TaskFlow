# Учебный маршрут

## 1. Посмотри интерфейс

Зарегистрируй первого пользователя, добавь клиента и создай заказ. После этого
переводи заказ между статусами и наблюдай за dashboard.

## 2. Проследи регистрацию

Открой файлы в таком порядке:

1. Форма регистрации в `web/index.html`.
2. Отправка запроса в `web/app.js`.
3. Endpoint `register` в `app/api/routes.py`.
4. Модель `RegisterRequest` в `app/schemas.py`.
5. Хеширование в `app/security.py`.
6. Таблица `User` в `app/models.py`.

## 3. Проследи создание заказа

1. Пользователь выбирает клиента и вводит сумму.
2. JavaScript отправляет `POST /api/orders`.
3. Pydantic проверяет client_id, название, статус и сумму.
4. API проверяет, что клиент существует.
5. SQLAlchemy создает заказ и связывает его с пользователем.
6. Ответ возвращает название клиента вместе с заказом.

## 4. Разберись с JWT

После входа токен сохраняется в браузере. Каждый защищенный запрос получает
заголовок `Authorization`. Dependency `get_current_user` проверяет подпись и
находит пользователя.
