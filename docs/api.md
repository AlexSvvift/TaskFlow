# API TaskFlow

Базовый адрес локального API:

```text
http://127.0.0.1:8001/api
```

Интерактивная документация: `http://127.0.0.1:8001/docs`.

## Авторизация

### POST `/auth/register`

```json
{
  "email": "admin@example.com",
  "full_name": "Admin User",
  "password": "StrongPass123"
}
```

Возвращает JWT и данные пользователя. Первый пользователь получает `admin`.

### POST `/auth/login`

Принимает email и пароль, возвращает токен.

### GET `/auth/me`

Возвращает текущего пользователя. Нужен заголовок:

```text
Authorization: Bearer <token>
```

## Dashboard

### GET `/dashboard`

Возвращает количество клиентов, заказов, активных и завершенных заказов, а
также сумму завершенной выручки.

## Клиенты

### GET `/clients`

Возвращает список клиентов.

### POST `/clients`

```json
{
  "name": "Иван Петров",
  "company": "ООО Север",
  "email": "ivan@example.com",
  "phone": "+7 900 000-00-00",
  "notes": "Позвонить после 15:00"
}
```

### PATCH `/clients/{id}`

Изменяет переданные поля клиента.

### DELETE `/clients/{id}`

Удаляет клиента. Нужна роль `admin`.

## Заказы

### GET `/orders`

Возвращает заказы. Для фильтра можно указать:

```text
/orders?order_status=in_progress
```

### POST `/orders`

```json
{
  "client_id": 1,
  "title": "Сайт компании",
  "description": "Лендинг и форма заявки",
  "status": "new",
  "amount": 150000
}
```

### PATCH `/orders/{id}`

Меняет название, описание, сумму или статус заказа.

### DELETE `/orders/{id}`

Удаляет заказ. Нужна роль `admin`.

## Коды ответа

| Код | Значение |
| --- | --- |
| `200` | запрос выполнен |
| `201` | объект создан |
| `204` | объект удален |
| `401` | нет токена или токен неверен |
| `403` | недостаточно прав |
| `404` | объект не найден |
| `409` | email уже используется |
| `422` | ошибка валидации данных |
